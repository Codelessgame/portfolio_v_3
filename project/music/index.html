NumPy Attention Music Generator

From-scratch Self-Attention neural network and MIDI music generator implemented purely in NumPy without deep learning frameworks

A deep dive into implementing the Transformer Self-Attention mechanism, modular neural layers, and analytical backpropagation from first principles using only Python and NumPy to train on the MAESTRO Piano MIDI dataset.

1

Step 1: MAESTRO MIDI Dataset Ingestion & Preprocessing

Automated dataset downloading via KaggleHub to pull the MAESTRO Piano MIDI corpus into a local workspace. Used PrettyMIDI to parse polyphonic piano performances, extracting note pitches, velocities, and step durations into structured NumPy matrices suitable for sequence modeling.

2

Step 2: Modular Neural Layers & Analytical Backpropagation in NumPy

Constructed an abstract Layer base class defining forward and backward contracts. Implemented custom Relu_layer and Leaky_Relu_layer with exact analytical gradient calculations (dZ = dL * d_relu, dW = X.T @ dZ, db = sum(dZ), dX = dZ @ W.T) to update weight matrices via gradient descent without automatic differentiation engines.

3

Step 3: Self-Attention Mechanism from First Principles (Q, K, V)

Built the core Attention module with learned Query, Key, and Value projection weight matrices (W_query, W_key, W_value). Implemented dot-product attention calculation and Softmax probability distribution normalization to dynamically weight long-range temporal dependencies across musical sequences.

4

Step 4: Training & Model Weights Serialization (.npz)

Trained the network on sequential MIDI fragments, tracking loss reduction across epochs. Serialized the learned projection weights into compressed NumPy archives (music_model_weights.npz) to enable autoregressive generation of original piano melodies.
